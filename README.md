# Dzen Finance Entry Lab 0.2.5 Alpha

Принятый автономный исследовательский макет. Только вымышленные данные.

Приложение: https://vandmitry.github.io/dzen-finance-entry-lab/

Оба расчёта, обучение, история и сохранение выполняются в браузере. Изменив параметры, нажмите «Пересчитать», затем «Сохранить вариант». Экспорт черновика недоступен до пересчёта. Очистка данных браузера удаляет локальную историю. Необязательная озвучка использует синтез речи браузера и произносит только названия тем.

Файл index.html побайтно совпадает с финальным GO-артефактом.
